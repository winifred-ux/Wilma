How it works

From message to verdict in three steps.

01 · Receive

Send any text

Post a message to /classify. Single message or batch of up to 50. JSON in, JSON out. CORS-enabled for browser apps.

02 · Classify

DistilBERT inference

A fine-tuned 135M-parameter DistilBERT processes the message, trained on Enron, SpamAssassin, UCI SMS, and the Kaggle 419 corpus.

03 · Respond

Verdict + explanation

Confidence-scored verdict in <100ms. Token-level explanations available via Integrated Gradients on a separate endpoint.

For developers

One curl. Any language.

Wilma is a standard REST API. Integrate from Python, Node, Go, or anything that speaks HTTP.

# Single classification
curl -X POST https://winifred12-wilma.hf.space/classify \
  -H "Content-Type: application/json" \
  -d '{"text": "URGENT BUSINESS ASSISTANCE..."}'

# Returns JSON
{
  "verdict": "scam",
  "confidence": 0.9998,
  "is_scam": true,
  "model": "DistilBERT v1 binary",
  "latency_ms": 37.4
}
