How to use your key

Pass your API key as a Bearer token in the Authorization header. Below are working code examples in three languages.

# Replace YOUR_API_KEY with one of your keys above curl -X POST https://winifred12-wilma.hf.space/classify \ -H "Authorization: Bearer YOUR_API_KEY" \ -H "Content-Type: application/json" \ -d '{"text": "URGENT: Your account suspended. Click bit.ly/scam-link"}'
# pip install requests import requests response = requests.post( "https://winifred12-wilma.hf.space/classify", headers={ "Authorization": "Bearer YOUR_API_KEY", "Content-Type": "application/json" }, json={"text": "URGENT: Your account suspended."} ) print(response.json())
const response = await fetch( "https://winifred12-wilma.hf.space/classify", { method: "POST", headers: { "Authorization": "Bearer YOUR_API_KEY", "Content-Type": "application/json" }, body: JSON.stringify({ text: "URGENT: Your account suspended." }) } ); const data = await response.json(); console.log(data);
