How she decides

Two minds.
Three honest answers.

Two separate AI models read every message. Wilma only says "block" when both agree. When they don't, she tells you so instead of guessing.

Pass · neither flags it "You're fine."

Neither mind found a scam signal. Even so, never share your OTP or PIN with anyone who asks for it.

Review · they disagree "Check it first."

She won't guess with your money. Call your bank on the number on your card before you do anything.

Block · both agree "Abeg, no pay."

Both minds are sure. Don't pay, don't click the link, don't reply. Delete it and move on.

For banks and fintechs

Put Wilma on your fraud team.

One API call returns pass, review or block, with both models' scores attached. Your analysts only need to look at the messages where her two minds disagree.

curl -X POST https://winifred12-wilma.hf.space/verdict \
  -H "Authorization: Bearer wlm_..." \
  -H "Content-Type: application/json" \
  -d '{"text": "Your OTP is 483920..."}'

# response
{
  "verdict": "review",
  "agreement": "one",
  "action": "Models disagree. Send to a human review queue.",
  "models": [ ...each model's scam_probability... ]
}
import requests

r = requests.post(
    "https://winifred12-wilma.hf.space/verdict",
    headers={"Authorization": "Bearer wlm_..."},
    json={"text": message},
)
verdict = r.json()["verdict"]  # "block", "review" or "pass"
const res = await fetch("https://winifred12-wilma.hf.space/verdict", {
  method: "POST",
  headers: { "Authorization": "Bearer wlm_...", "Content-Type": "application/json" },
  body: JSON.stringify({ text: message }),
});
const { verdict } = await res.json(); // "block", "review" or "pass"
