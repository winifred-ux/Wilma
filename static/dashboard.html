Get started

Three steps to your first verdict.

  1. 1
    Create an API key
    Keys are shown once and stored only as a hash. Create one
  2. 2
    Send your first request
    POST the message text to /verdict with your key.
  3. 3
    Act on the verdict
    Block, send to review, or pass. Read the docs

Quick start

curl -X POST https://winifred12-wilma.hf.space/verdict \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer wlm_your_key" \
  -d '{"text": "Your BVN has been blocked"}'
